# User Manual

This manual walks end users through the Trace Trail application from signup to
ongoing maintenance.

---

## 1. Account Creation

1. Visit `https://app.tracetrail.com/signup`.
2. Enter email, username, and secure password (12+ characters).
3. Verify your email if prompted.

---

## 2. Connecting Accounts

1. Navigate to **Connections**.
2. Click **Add Connection** and choose a platform.
3. Authorize Trace Trail via OAuth. We request the minimum scopes necessary to
   read public data and security signals.
4. Repeat for each platform you want to monitor.

---

## 3. Running an Analysis

1. Go to **Dashboard** and click **Run Analysis** (or schedule via Settings).
2. Wait a few seconds while FastAPI + AI module compute your scores.
3. Review the summary on the dashboard once complete.

---

## 4. Reviewing Recommendations

1. Open the **Recommendations** tab.
2. Filter by priority or category (Security, Privacy, Hygiene).
3. Expand a card to see detailed instructions.
4. Click **Mark Complete** when finished; the next analysis will validate it.

---

## 5. Managing Challenges

1. Visit **Challenges** to join gamified journeys.
2. Track progress in the challenge drawer.
3. View earned badges under your profile avatar.

---

## 6. Reports

- Generate PDF/CSV summaries under **Reports**.
- Share downloads securely via expiring links (copy icon next to each report).
- History tab stores 30 days of reports.

---

## 7. Notifications & Settings

- Switch to **Settings** → **Notifications** to control email/push alerts.
- Customize privacy preferences, display name, and theme (light/dark).
- Manage API tokens (future) and delete your account.

---

## 8. Support

- Use in-app chat (coming soon) or email support@tracetrail.com.
- Report bugs via the feedback widget in the footer.
- Track feature releases in `CHANGELOG.md`.
