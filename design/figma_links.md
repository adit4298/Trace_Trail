## Access & Permissions

### For Developers
- **View Access**: All design files
- **Export Assets**: Developer mode enabled
- **Inspect**: All CSS properties visible
- **Comment**: Encouraged for feedback

### For Stakeholders
- **View Access**: Main screens and prototypes
- **Comment Access**: For feedback

### For Design Team
- **Full Edit Access**: All files
- **Version Control**: Via Figma auto-save + Abstract

## How to Use Figma Files

### For Developers
1. **Open Design File**: Click link above
2. **Enable Developer Mode**: Toggle in top-right
3. **Select Element**: Click any component
4. **View CSS**: Right panel shows all properties
5. **Export Assets**: Click export button for production assets

### Asset Export Settings
- **Icons**: SVG (optimized)
- **Images**: PNG (2x resolution)
- **Logos**: SVG + PNG (multiple sizes)
- **Illustrations**: SVG
